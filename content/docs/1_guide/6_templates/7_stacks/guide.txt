Title: Template stacks

----

Intro: Push output from any template or snippet onto a named stack and render that stack somewhere else, e.g. to collect the CSS and JavaScript of your block snippets in the `<head>` of the page.

----

Text:

A block snippet knows best which styles and scripts it needs. But by the time a block is rendered, the `<head>` of your page has already been written. Stacks solve this: you push output from anywhere, render the stack anywhere, and Kirby puts everything in the right place at the end.

## Push to a stack

Wrap any output in (helper: push) and (helper: endpush) to add it to a stack. The output doesn't show up where you push it, but wherever the stack is rendered:

```php "/site/snippets/blocks/gallery.php"
<?php push('head') ?>
<link rel="stylesheet" href="<?= url('assets/css/gallery.css') ?>">
<?php endpush() ?>

<figure class="gallery">
  <!-- … -->
</figure>
```

For short content, pass it as second argument instead:

```php
<?php push('head', '<meta name="robots" content="noindex">') ?>
```

## Render a stack

Call (helper: stack) with the name of the stack where its content should appear:

```php "/site/snippets/header.php"
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title><?= $page->title()->esc() ?></title>
  <?= css('assets/css/index.css') ?>
  <?php stack('head') ?>
</head>
<body>
```

## Order doesn't matter

In the example above, the header snippet renders the `head` stack before any block has been rendered. That's fine. While Kirby renders your template, `stack()` only leaves a placeholder. Once the whole template is rendered, Kirby replaces each placeholder with everything that has been pushed to that stack, no matter whether it was pushed before or after.

This means you can push from any template or snippet, including snippets that are rendered inside other snippets, like blocks or layouts.

## Push only once

Blocks often appear more than once on a page. Without precautions, three gallery blocks would add the same stylesheet three times. Pass `unique: true` to add identical content only once:

```php "/site/snippets/blocks/gallery.php"
<?php push('head', css('assets/css/gallery.css'), unique: true) ?>
```

This also works with output buffering:

```php
<?php push('footer', unique: true) ?>
<script src="<?= url('assets/js/gallery.js') ?>" defer></script>
<?php endpush() ?>
```

Kirby compares the exact content, so make sure that every push of the same asset produces exactly the same output.

## Render options

By default, the entries of a stack are joined with line breaks. Pass a different `glue` string to change this, or set `return: true` to get the result instead of echoing it:

```php
// join the entries without line breaks
<?php stack('head', glue: '') ?>

// return instead of echo
<?php $head = stack('head', return: true) ?>
```

A stack is empty after it has been rendered. To render the same stack in more than one place, pass `clear: false` to every call but the last:

```php
<?php stack('notices', clear: false) ?>
<!-- … -->
<?php stack('notices') ?>
```

## Example: block assets

Here's how a site with a blocks field can load the CSS and JS of each block type only on pages that actually use it.

The header and footer render the stacks:

```php "/site/snippets/header.php"
<head>
  <meta charset="utf-8">
  <title><?= $page->title()->esc() ?></title>
  <?= css('assets/css/index.css') ?>
  <?php stack('styles') ?>
</head>
<body>
```

```php "/site/snippets/footer.php"
  <?php stack('scripts') ?>
</body>
</html>
```

Each block snippet pushes what it needs:

```php "/site/snippets/blocks/slider.php"
<?php push('styles', css('assets/css/blocks/slider.css'), unique: true) ?>
<?php push('scripts', js('assets/js/blocks/slider.js', ['defer' => true]), unique: true) ?>

<div class="slider">
  <?php foreach ($block->images()->toFiles() as $image): ?>
  <img src="<?= $image->url() ?>" alt="<?= $image->alt()->esc() ?>">
  <?php endforeach ?>
</div>
```

The template doesn't need to know about any of it:

```php "/site/templates/default.php"
<?php snippet('header') ?>

<main>
  <?= $page->text()->toBlocks() ?>
</main>

<?php snippet('footer') ?>
```

A page with three sliders gets `slider.css` and `slider.js` exactly once. A page without a slider doesn't load them at all.

<info>
`push()`, `endpush()` and `stack()` are global helper functions. If your project or one of your libraries already defines functions with the same names, (link: docs/reference/templates/helpers#deactivate-a-helper-globally text: deactivate Kirby's helpers).
</info>
