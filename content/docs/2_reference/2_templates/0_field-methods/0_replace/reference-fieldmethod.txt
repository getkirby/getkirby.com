Text:

<warning>
All placeholders in the field value run as queries with full access to Kirby's PHP API, not only the ones you pass with `$data`. Only use this method with fields that you would trust to contain PHP code. Never use it with content that comes from site visitors or with fields that Panel users with limited permissions can edit.
</warning>

(link: docs/guide/blueprints/query-language#only-run-trusted-queries text: Learn more about trusted queries ›)

----

Examples:

Given the field contains string templates, use this method to replace them with values:

Example text:

```text
Text: The company behind {{ product }} and the responsible data controller for this website is the {{ company }}.
```

```php
<?= $page->text()->replace(
    [
        'company' => 'Content Folder GmbH & Co. KG',
        'product' => 'Kirby CMS'
    ]
);
```

Will result in

```
The company behind Kirby CMS and the responsible data controller for this website is the Content Folder GmbH & Co. KG.
```
