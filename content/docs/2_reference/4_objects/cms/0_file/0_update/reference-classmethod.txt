Auth: files.update

----

Text:

## Example

```php
if ($file = $page->file('myimage.jpg')) {

  try {

    $newFile = $file->update([
      'caption' => 'This is a really nice image',
      'year'    => 2014
    ]);

    echo 'The meta info has been updated';

  } catch(Exception $e) {

    echo 'The meta info could not be updated';
    // optional reason: echo $e->getMessage();

  }

}
```

## Objects as values

Each field of the file's blueprint converts Kirby objects and collections into the format it stores:

```php
$newFile = $file->update([
  'photographer' => $kirby->user('bastian@example.com'),
  'related'      => $file->siblings()->images()->limit(3),
  'date'         => new DateTime(),
]);
```

## Multi-language installation

In a multi-language installation, you can pass the language of the meta data you want to update as a second argument:

```php
if ($file = $page->file('some-file.jpg')) {
  $newFile = $file->update([
    'some_field' => 'new value'
  ], 'en');
}

if ($file = $page->file('some-file.jpg')) {
  $newFile = $file->update([
    'some_field' => 'new value'
  ], site()->language()->code());
}
```
