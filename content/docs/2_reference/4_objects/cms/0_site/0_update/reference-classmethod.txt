Auth: site.update

----

Examples:

```php
try {
  $site->update([
    'title'       => 'My Site',
    'description' => 'it is really nice',
  ]);

  echo 'The site info has been updated';

} catch(Exception $e) {
  echo $e->getMessage();

}
```

### Objects as values

Each field of the site's blueprint converts Kirby objects and collections into the format it stores:

```php
$site->update([
  'logo'     => $site->image('logo.svg'),
  'featured' => $site->children()->listed()->limit(3),
  'editors'  => $kirby->users()->role('editor'),
  'launch'   => new DateTime(),
]);
```
