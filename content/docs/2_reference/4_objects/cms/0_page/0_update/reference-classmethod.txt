Auth: pages.update

----

Examples:

```php
try {

  $newPage = page('mypage')->update([
    'title'        => 'A new title',
    'text'         => 'Some text',
    'anotherfield' => 'Some more data'
  ]);

  echo 'The page has been updated:';

} catch(Exception $e) {

  echo $e->getMessage();

}
```

### Updating a field by callback

```php
$newPage = $page->update([
  'title' => function($title) {
    return Str::lower($title);
  }
]);
```

### Objects as values

Each field of the page's blueprint converts Kirby objects and collections into the format it stores:

```php
$newPage = $page->update([
  'cover'   => $file,
  'related' => $page->siblings()->listed(),
  'authors' => $kirby->users()->role('editor'),
  'text'    => $page->text()->toBlocks(),
  'gallery' => $other->gallery(),
  'date'    => new DateTime(),
]);
```

## Multi-language site
Use the optional `$lang` parameter to specify the language you want to update.

```php
try {

  $newPage = page('mypage')->update([
    'title'        => 'A new title',
    'text'         => 'Some text',
    'anotherfield' => 'Some more data'
  ], 'en');

  echo 'The page has been updated';

} catch(Exception $e) {

  echo $e->getMessage();

}
```
