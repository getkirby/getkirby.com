----

Text:

```php "/site/plugins/urls/index.php"
Kirby::plugin(
  name: 'my/urls',
  extends: [
    'components' => [
      'url' => function (Kirby $kirby, string|null $path = null, array|string|null $options = null): string {
          $original = $kirby->nativeComponent('url');
          return $original($kirby, $path, $options);
      }
    ]
  ]
);
```
