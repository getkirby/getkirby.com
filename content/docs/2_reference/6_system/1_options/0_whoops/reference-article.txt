Intro: Enables/disables the Whoops debugger

----

Text:

The Whoops debugger is a comfortable way to detect issues in your templates and plugins and fix them quickly. It is activated by default when Kirby is in (link: docs/reference/system/options/debug text: debug mode), but if you prefer you can disable it to fall back to regular PHP error handling.

```php "/site/config/config.php"
return [
	'whoops' => false
];
```

With the (link: docs/reference/system/options/editor text: `editor` option), you can open the files from the Whoops error page right in your code editor.

## Hide sensitive data

The Whoops error page lists the request data and the environment, e.g. the values of `$_SERVER` and `$_ENV`. Use the `whoops.blocklist` option to mask the values of sensitive variables like passwords or API keys:

```php "/site/config/config.php"
return [
	'whoops' => [
		'blocklist' => [
			'_ENV'    => ['DB_PASSWORD', 'API_KEY'],
			'_SERVER' => ['DB_PASSWORD', 'API_KEY']
		]
	]
];
```

The keys are the names of the superglobals: `_GET`, `_POST`, `_FILES`, `_COOKIE`, `_SESSION`, `_SERVER` and `_ENV`.
